# Battleship Game 🚢

A digital version of the classic **Battleship** strategy game built as a programming project. Players attempt to locate and sink hidden ships by guessing grid coordinates.

##  Features
- Grid-based game board  
- Ship placement system  
- Hit and miss detection  
- Turn-based gameplay  
- Win/Loss condition logic  

##  Concepts Practiced
- Arrays and grid logic  
- Conditional statements  
- Loops and iteration  
- Game state management  
- User input handling  

##  Tech Stack
- Java 

##  Project Purpose
This project was developed to strengthen problem-solving skills and understand how game logic, coordinate systems, and state tracking work in programming.

##  How to Run

1. Make sure Java is installed
2. Download the project files
3. Open terminal in project folder
4. Compile:
   javac Main.java
5. Run:
   java Main
